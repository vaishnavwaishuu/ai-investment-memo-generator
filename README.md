AI Investment Memo Generator — MemoForge
An AI-powered investment memo generator built with React and Claude API.
Built to solve a real problem: generating startup investment memos manually was taking hours at my UK-based research analyst internship.
What it does
Enter any startup name, domain, country and funding stage — and get a full professional VC investment memo in seconds including Executive Summary, Investment Thesis, Risk Analysis, Competitive Landscape and an AI-generated analyst scorecard with Strong Buy / Buy / Hold / Pass rating.
Tech used
React, Claude API (Anthropic), JavaScript
Note
Requires a Claude API key to run. This is a working prototype built as part of my internship research workflow.
